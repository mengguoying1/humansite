# 🚀 社区速通与物理引擎 Bug 教学指南

虽然开发商最初将《人类一败涂地》设计为一款慢节奏的物理合作解谜游戏，但这个滑稽摇晃的物理引擎中隐藏着速通玩家多年来不断发掘的惊天秘密。通过利用碰撞箱体积溢出、帧率导致的物理计算延迟以及手臂拉伸极限，你可以实现高空飞跃并无限攀爬垂直墙壁。

本指南将详细解析社区中用于打破游戏常规难度的四大核心黑科技技巧。

## 🧗 一、左右划水爬墙法 (Vertical Flap / Paddling)
*   **难度系数**：★★★★☆
*   **适用场景**：攀爬没有任何凸起或接缝的平整垂直高墙，可无限向上爬。
*   **物理原理**：当 Bob 抓住墙面并左右转动视角时，其肩关节和手臂会伸展拉长。通过交替左右手抓取墙壁，同时快速摆动视角，可以突破垂直攀爬的高度上限。
*   **具体操作步骤**：
    1. 面朝墙壁站立，双手高举起跳，抓住你能达到的最高点。
    2. 松开**右手**鼠标键，左手保持抓住墙面。
    3. 快速将鼠标向**右侧**甩动（约 45-60 度），此动作会使 Bob 侧身并将悬空的右手送往更高处。
    4. 按住鼠标右键，让**右手**抓住这个全新的高度。
    5. 松开**左手**鼠标键，快速将鼠标向**左侧**甩动。
    6. 按住鼠标左键，让**左手**抓住更高的左侧墙面。
    7. 循环这一节奏：*放右手 -> 向右拧身 -> 抓右手 -> 放左手 -> 向左拧身 -> 抓左手*。Bob 在墙上的动作看起来会非常像在空中“划水”或“扑翼”。

## 🪂 二、单手极限摆荡 (Single-Hand Super Swing)
*   **难度系数**：★★★☆☆
*   **适用场景**：利用单个吊钩、绳索或铁链荡过极宽的深渊，获取双倍的惯性速度。
*   **物理原理**：双手齐抓虽然稳妥，但会分散重心并限制摆动幅度。仅使用**一只手**抓取时，Bob 的身体会像偏心悬挂的钟摆，从而产生极高的旋转扭矩。
*   **具体操作步骤**：
    1. 跳向秋千、绳索或吊环，**只用一只手**（例如左手）将其抓住。
    2. 在向前摆动时，按住向前移动键（<span class="kbd-key">W</span>）。
    3. 当摆荡到达最前端的最高点时，先不要放手。迅速将视角转动 90 度偏离运动方向，并按下 <span class="kbd-key">A</span> 或 <span class="kbd-key">D</span> 键，让 Bob 的身体绕着绳索扭转。
    4. 往回摆，然后再荡向前。在第二次前摆时，利用刚才身体拧转释放的扭矩。
    5. 这种扭转动能会完全转化为水平初速度。在第二次荡到最高点的瞬间松手，你将被甩向极远的地方，飞行距离是普通双人秋千的两倍。

## 🏹 三、吊索势能惯性弹射 (Slingshot Glide)
*   **难度系数**：★★★★★
*   **适用场景**：从滑索、吊绳或铁链上松手的一瞬间将自己发射出去，飞越整张地图。
*   **物理原理**：如果在 Bob 身体被拉伸到极致的瞬间松手，物理引擎会瞬间释放拉伸所积蓄的弹性势能。这会将缆绳的拉力瞬间转化为极高的前向动能。
*   **具体操作步骤**：
    1. 抓住悬挂滑索的手柄或吊绳。
    2. 随滑索下滑积累速度。在接近滑轨终点时，**按住向后键**（<span class="kbd-key">S</span>），这会让 Bob 的身体拖在吊钩后方，将手臂关节拉到最长。
    3. 突然松开 <span class="kbd-key">S</span> 键并瞬间按下向后前的 <span class="kbd-key">W</span> 键，Bob 的身体会像橡皮筋一样猛烈向前反弹。
    4. 在 Bob 的身体反弹到吊钩正下方的极短一瞬间，松开鼠标左右键。
    5. 如果时机精准到微秒级，你的惯性速度将翻倍，在空中滑翔数百米直接飞越关卡。

## 🖥️ 四、帧率调节逃课 (FPS Checkpoint Skip)
*   **难度系数**：★★★☆☆
*   **适用场景**：强行穿过紧闭的铁栅栏大门，或强行卡过检查点触发器。
*   **物理原理**：《人类一败涂地》的碰撞检测频率与游戏帧率（FPS）强绑定。在极高或极低的帧率下，物理引擎的单帧判定会发生滞后或算力溢出，当 Bob 受到挤压时，其肢体很容易穿透固定的墙壁和门体模型。
*   **具体操作步骤**：
    1. 走到有缝隙的门或铁栅栏前（如“城堡”或“黑暗”关卡的铁栅栏门）。
    2. 将 Bob 的身体横过来，使劲往大门转轴与石墙交界处的夹角里挤。
    3. 双手抓住缝隙内部的墙壁，拼命往里拉扯自己。
    4. **调控帧率**：速通玩家会通过快捷键或显卡设置，将游戏帧率锁定在 15 帧（制造严重的物理延迟）或解锁至 300 帧以上（制造超高频的物理碰撞修正）。
    5. 快速左右摇晃鼠标视角。物理碰撞求解器在这一瞬间无法及时计算出 Bob 的边界，判定失效，你就会直接被“挤”到大门的另一侧。
